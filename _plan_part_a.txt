# Multi-Platform Subtitle Extraction -- Implementation Plan

## Executive Summary

Expand the browser extension from YouTube-only to support Netflix, Vimeo, Facebook, Udemy, Coursera, TikTok, Twitter/X, and Twitch. Three workstreams: (1) a platform registry with declarative configs + optional custom logic, (2) robust HTML5 TextTrack detection, (3) tab audio capture for STT fallback. All changes are additive -- YouTube continues working exactly as it does today.

---

## 1. Architecture Overview

### Current Flow

```
VideoTranslator._tryExtractSubtitles()
  findSubtitleTracks(video)        <-- one-shot TextTrack check
  TextTrack found? -> getAllCues() <-- buffered mode
  No TextTrack? -> _tryPlatformSubtitles()
       isYouTube()? -> _tryYouTubeApiCaptions() -> DOM observer
       else -> _startSpeechRecognition()  <-- MICROPHONE (broken)
```

### Target Flow

```
VideoTranslator._tryExtractSubtitles()
  TextTrackDetector.detect()       <-- NEW: reactive TextTrack detection
    Listen for addtrack event
    Retry with backoff (up to 10s)
    Smart track selection (manual > ASR, language preference)
    TextTrack found? -> buffered mode (existing)

  No TextTrack? -> _tryPlatformSubtitles()
    PlatformRegistry.match(url) -> config?
      config.captionSelector? -> observeDomSubtitles(config)
      config.pageScript? -> inject MAIN world script + IPC bridge

    No platform match -> _startAudioCapture()  <-- NEW: tab audio STT
      chrome.tabCapture -> AudioContext -> Whisper/Web Speech
      Fallback: existing SpeechRecognizer (microphone)
```
